# Frame Budget downloads

Installers for the Frame Budget Mac app from iCare Advisors. This repository holds downloads only.

**Install:** open the [latest release](../../releases), download the `.dmg`, drag **Frame Budget** to
Applications and open it. It is signed and notarized by Apple. Requires a Mac with Apple Silicon (M1 or later).

The app checks this page for updates from **File > Check for Updates…**.
